# El Fogón de la Abuela

Sitio web responsive hecho con HTML, CSS y JavaScript puro.

## Archivos
- `index.html`: página comercial / restaurante / delivery.
- `eventos.html`: página de eventos y catering.
- `styles.css`: estilos responsive.
- `script.js`: menú móvil, carruseles, tabs, modales, testimonios y formulario.

## Cómo abrir
Abre `index.html` directamente en el navegador o usa Live Server en VS Code.

## Nota
Las imágenes usan URLs remotas de Unsplash, por lo que requieren conexión a internet.
Cambia el número de WhatsApp `51999999999` por el número real.
